## 📊 每日工作模板

### 每天的标准流程：

#### 🌅 上午（2-3小时）
1. **回顾昨天**（10分钟）
   - 看昨天完成了什么
   - 看我的Review意见
   
2. **计划今天**（10分钟）
   - 对照工作清单
   - 确定今天目标
   
3. **咨询我**（30分钟）
   - 今天要实现什么？
   - 有什么不清楚的设计？
   - 预期会遇到什么问题？
   
4. **学习和准备**（1-2小时）
   - 阅读相关文档
   - 学习相关技术
   - 准备Cursor指令

#### 🌞 下午（2-3小时）
1. **Cursor实施**（2小时）
   - 按照我给的设计
   - 让Cursor生成代码
   - 解决编译错误
   
2. **自测和调试**（1小时）
   - 运行单元测试
   - 功能测试
   - 记录问题

#### 🌙 晚上（1小时）
1. **整理代码**（20分钟）
   - 格式化
   - 添加注释
   - 提交Git
   
2. **给我Review**（20分钟）
   - 整理今天的代码
   - 列出遇到的问题
   - 发给我
   
3. **总结和预习**（20分钟）
   - 写今天学到了什么
   - 看明天要做什么
